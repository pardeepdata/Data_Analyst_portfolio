Sales Data Analysis Portfolio Project
📊 Project Overview
This is a complete Data Analysis Portfolio Project that demonstrates the end-to-end process of transforming raw sales data into interactive dashboards and actionable business insights. This project integrates Excel, SQL, and Power BI.
🛠️ Tools & Technologies Used
 Microsoft Excel: Used for initial data cleaning, structuring, and exploring the raw dataset.
 SQL: Used to write queries for data extraction and fetching specific business insights.
 Power BI: Used for building interactive sales reports, data modeling, and visualization (⁠.pbix⁠).
🔄 Step-by-Step Project Work
1. Excel Phase (Data Preparation):
 Imported the raw sales records into ⁠Sales_Portfolio_Data.xlsx⁠.
 Performed data validation and formatting checks to ensure error-free analysis.
2. SQL Phase (Data Querying):
 Wrote custom SQL queries (⁠queries.sql⁠) to extract key metrics such as total sales, top-performing products, and regional performance.
 Queried the database to answer core business questions.
3. Power BI Phase (Dashboard & Visualization):
 Imported the dataset into Power BI Desktop to create ⁠sales.pbix⁠ and ⁠Sales_Dashboard_Portfolio.pbix⁠.
 Designed professional interactive dashboards featuring total sales cards, total orders, city-wise sales breakdowns, and product-quantity bar charts.
📈 Key Insights & Findings
 Top Products: Identified top-selling product categories using clear column charts.
 City Performance: Analyzed regional sales performance across multiple cities (such as Milan, Rome, and Turin) to find primary markets.
 Overall Metrics: Summarized total revenue and order volume using high-level KPI cards.
